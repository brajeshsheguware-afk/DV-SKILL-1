# DV Task 1 – Superstore Sales Data Analysis

##  Project Description

This project is about analyzing **Superstore sales data** using Python.
The dataset is loaded and analyzed using Pandas and NumPy. Different charts are created using Matplotlib and Seaborn to understand the sales data.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

##  Files

* `DV_TASK_1.ipynb` – Jupyter/Google Colab notebook
* `dv_task_1.py` – Python source code

##  Work Done in This Project

* Loaded the Superstore dataset
* Displayed the first few records
* Checked dataset information
* Generated descriptive statistics
* Converted Order Date and Ship Date into date format
* Calculated delivery days
* Checked available categories
* Checked missing values
* Calculated total sales for each category
* Created a bar chart for sales by category
* Created a histogram to show sales distribution

The project calculates **Delivery Days** using the difference between Ship Date and Order Date.

##  Visualizations

### Sales by Category

A bar chart is used to show the total sales for each product category.

### Sales Distribution

A histogram is used to understand the distribution of sales values.

##  Objective

The main objective of this project is to understand the Superstore dataset and use basic data analysis and visualization techniques to identify sales patterns.
